# neboiwenofu.com

Personal site — hand-built on plain HTML/CSS/JS, no framework, hosted on
GitHub Pages.

Sections: About, Writing, Projects, Reading.

- `index.html` — home (includes about content: experience, education, contact)
- `writing.html` — writing index; individual essays live in `writings/`
- `projects.html` — projects (unlinked from nav until there's something to share)
- `reading.html` — reading list
- `styles.css` — the one shared stylesheet
- `writings/medium-import/` — Markdown sources of the 2016–2018 Medium archive
  (migrated as-is with original dates)
